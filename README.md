MihonRPC

Discord Rich Presence integration for Mihon.

MihonRPC is an experimental open-source project aiming to bring Discord Rich Presence to Mihon, an Android manga reader.

Planned Features

- Display the manga currently being read.
- Show the current chapter.
- Display manga cover artwork.
- Track reading duration.
- Reading and inactive states.
- Privacy controls and incognito mode.
- NSFW content filtering.

Project Status

Phase: Research and preparation
Version: 0.0.1
Development: Not started

Discord integration is subject to official platform eligibility and technical verification.

Planned Technologies

- Kotlin
- Android SDK
- Gradle
- Discord Social SDK (subject to approval and compatibility verification)
